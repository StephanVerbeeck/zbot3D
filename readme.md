# Z-bot 3D
## Program
This program is a simplistic 3D simulation of the Z shaped wheeled robot.
- Buttons [0] through [9] make robot upper body assume standard postures.
- Movement of the robot is done by [Q],[W],[E],[A],[S],[D] buttons with [shift] for extra speed
- Movements of the robot arms are done by sliders on a Novation Launchkey midi board
- Movement of the camera view is done with the mouse (scrollwheel for move nearer/away)
- mouse click locks camera position and orientation (otherwise looks at robot)
- [F] toggles full-screen mode
- [M] shows mesh (wire-frame versus solid view mode)
